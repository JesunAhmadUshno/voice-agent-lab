# voice-agent-lab

**Question.** Where does every millisecond of a voice-agent turn go,
stage by stage, locally against a cloud speech pipeline?

**Headline.** In a stand-in voice loop (typed transcripts, a keyword rule and sine-tone audio; no real speech model or LLM), audio synthesis was the largest stage in 20 of 20 turns and took 87.6% of the mean turn (95% t interval 87.5 to 87.7%, 5 runs on one machine); the median turn took 1.316 ms (95% t interval 1.314 to 1.318 ms), inside the 100 ms budget, and the rule understood only 9 of 20 held-out paraphrases.

**Field.** ML and AI research. **Job family.** Applied AI engineering
(real-time voice and audio systems).

**Verdict.** Functional, not pre-registered. Tests pass in CI on Python
3.11 and 3.12, the Build results regenerate byte for byte from the
committed cases by one command, and the voice loop under study has run
end to end with its evidence in experiments/ and results/. The system
that ran is a stand-in: no ASR model, TTS voice or LLM ever ran, and the
cloud side is modelled from stated constants, never measured. No plan
was locked before the results (PROPOSAL.md says why), so the verdict is
capped at Functional until a locked confirmatory cycle runs.

Live dashboard: https://jesunahmadushno.github.io/voice-agent-lab/
(talk to the rule agent in your browser, interrupt it, add ASR noise,
and replay the recorded latency runs; built from site/ by
.github/workflows/pages.yml).

## Reproduce

```text
python -m unittest discover -s tests -p "test_*.py" -v
python src/run_build.py && git diff --exit-code results/build.json
python src/run_deep.py /tmp/deep.json
python src/run_probes.py /tmp/probes.json
```

Python 3 standard library only, no dependencies, CPU only, under a
minute in total. The first line runs every test, including the check
that the headline numbers above match the evidence file. The second
regenerates the Build results and fails if one byte differs. The timed
runners (run_learn.py, run_deep.py, run_probes.py) measure wall-clock
time, so their numbers vary by run and machine; given no path, each
writes a new dated file in experiments/runs/ and refuses to overwrite
one. The headline comes from experiments/runs/2026-11-07-probes-aarch64.json;
REPORT.md traces every headline number to its field.
